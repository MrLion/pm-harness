# Scenario

## Main scenario

**Who:** Adults on employer-sponsored high-deductible health plans.
**Situation:** Choosing outpatient imaging.
**Problem:** Cannot estimate real out-of-pocket cost before booking.
**Why it matters:** Cost uncertainty leads to postponed care, surprise bills, and reduced trust.

## Example mapping

| Template | What this scenario shows |
|---|---|
| Problem | Real out-of-pocket uncertainty before imaging |
| Opportunity | Upfront cost estimator + provider matching |
| Research | Consumer decision friction + public cost-transparency data |
| Persona | Cost-conscious HDHP adult |
| Experiment | Patient interviews before building the product |
| PRD | Transparent outpatient cost-estimator MVP |
| Release | Pilot in two outpatient clinics |
| Review | Did postponed care fall? Did unexpected-bill complaints fall? |
